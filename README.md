# 矿山尾矿库监测计划与异常处置审阅平台

基于Angular、Angular Material、NgRx、Angular Router、RxJS、HttpClient、MapLibre GL、Turf.js、Nx和TypeScript的独立前端工程。无后端时自动使用本地模拟数据和浏览器跨窗口存储，界面内操作保留版本和审计。

## 功能

- 位移、水位、渗流、降雨监测点，MapLibre测点图层和Turf巡检路线长度。
- 报警值、变化速率与阈值版本查看。
- 监测计划、阈值、补传/补录读数统一绑定版本依据；未关闭异常立即失效重算，已关闭异常保留原依据并标记复议。
- 异常队列、现场复核、证据、复测评估和专业意见并存，并显示同一版本依据。
- 复核与会签按先到者生效，后到者保留内容并提示冲突。
- 写入失败保留未完成批次并可幂等重试，不重复追加审计。
- 处置方案、重大异常应急联动、负责人审批和关闭条件校验。
- 原始读数追加式留痕，所有修订形成独立版本和审计时间线。
- JSON审阅包导出版本依据和复议清单。

端口为`18462`。

```bash
npm install
npm run build
npm run dev
```
