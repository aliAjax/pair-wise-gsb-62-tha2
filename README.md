# 矿山尾矿库监测计划与异常处置审阅平台

基于Angular、Angular Material、NgRx、Angular Router、RxJS、HttpClient、MapLibre GL、Turf.js、Nx和TypeScript的独立前端工程。无后端时自动使用本地模拟数据，界面内操作保留版本和审计。

## 功能

- 位移、水位、渗流、降雨监测点，MapLibre测点图层和Turf巡检路线长度。
- **统一版本依据**：监测计划生效、自动读数、人工补录读数都挂入同一条单调递增的依据时间线（`basisHistory`）；阈值、读数、复核、专业意见、方案、会签、关闭快照、审计均携带 `basisVersion`，页面、异常队列与JSON导出共用同一依据视图。
- **依据变更联动**：新监测计划或补录读数生效后，影响范围内待处理/调查中/待审批/已会签的异常立即转为「已失效待重算」，旧复核与会签标失效但保留，并按新阈值/读数重算级别；已关闭异常冻结当时的关闭依据，仅标记「需要复议」并给出原因，不按旧依据继续执行。
- **乐观并发（先到先得）**：复核、方案、会签、关闭均携带异常版本基线，两个窗口同时提交时先到者写入生效，后到者收到冲突提示且填写内容完整保留，可按新版本一键重提。
- **批次写入与审计幂等**：所有写操作走同一串行批次管线；写入失败时未完成批次保留、可重试（或放弃），审计按批次号幂等落库，重试不会重复追加审计。
- 异常队列、现场复核、证据、复测评估和专业意见并存；处置方案、重大异常应急联动、负责人会签和关闭条件校验。
- 原始读数（含补录）只读，所有修订形成独立版本和审计时间线。
- JSON审阅包导出（含当前依据版本、依据时间线及每条异常的依据/关闭快照/复议标记）。
- 异常处置页提供「窗口A/窗口B」并行提交按钮和「模拟写入服务故障」开关，便于现场演示并发冲突与失败重试。

端口为`18462`。

```bash
npm install
npm run build
npm run dev
```
